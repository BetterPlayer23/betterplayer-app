# BetterPlayer

Stake credits on your own EA FC 1v1 matches. Beta: credits only, no real money.

Built with Expo (React Native), Expo Router and Firebase.

- Web preview: https://betterplayer23.github.io/betterplayer-app/ (updated on every push to `main`)
- Run locally: `npm install`, then `npm run web`
- Project rules: see [CLAUDE.md](CLAUDE.md)
